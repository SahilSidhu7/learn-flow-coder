# Learn Flow Coder

An interactive coding-learning platform — pick a language, work through topics and subtopics, and follow personalized courses with an in-browser Monaco code editor.

## Pages

- Languages → Topics → Subtopics learning flow
- Personalized learning and personal courses
- Pricing and About pages

## Stack

React + TypeScript + Vite, Tailwind CSS, shadcn/ui, Monaco Editor, Supabase.

## Run

```sh
npm install
npm run dev
```
